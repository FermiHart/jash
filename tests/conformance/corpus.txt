# ===========================================================================
# jash shell-language conformance corpus            oracle: /bin/bash 3.2
# ===========================================================================
# Format:  <category>::<one line of shell>
#   - the separator is the FIRST '::' on the line
#   - <NL> becomes a newline, <TAB> becomes a tab (see run-conformance.sh)
#   - trailing spaces are significant and deliberate on some lines
#   - a case PASSES when stdout AND exit status match bash's
#
# Sandbox fixture present for every case (LC_ALL=C):
#   a.txt ab.txt b.txt c.log data.txt empty.txt nums.txt "two words.txt"
#   .hidden  sub/  sub/inner.txt  home/
#   data.txt = alpha/beta/gamma/delta   nums.txt = 3/1/2
#
# jash shadows cat, wc, sed, awk, grep, ls, cp, mv, rm, touch with builtins.
# Cases that only need a neutral helper therefore call /bin/cat, /usr/bin/wc
# and /usr/bin/grep by absolute path: this file measures the LANGUAGE, and
# tests/conformance/run_conformance.sh already measures the builtin tools.
#
# Exclusions and their justification: see EXCLUSOES.md.  Nothing was ever
# removed from this corpus for the reason "jash fails it".
# ===========================================================================
