## 0. The contract

You implement two files:

## 1. Gate 0: it BOOTS

## 2. Gate 1: sysid (≈30 lines)

Easiest provider. Read the native uname-equivalent into `osif_sysid_t`.
Flip `OSIF_CAP_SYSID` ON in `bear_osinfo_caps()`. Run:
```
./build/jash -c 'osif check'
```
You should see one PASS. Tier D → Tier C.

## 3. Capability order (recommended)

Order by (consumer value × implementation cost):
1. **SYSID** — uname builtin works
2. **PROC**  — ps/kill work
3. **MEM**   — ps memory footer + statusbar mem segment
4. **MOUNTS** — df works
5. **UPTIME** — statusbar uptime
6. **LOADAVG** — statusbar load
7. **NET**   — statusbar net segment
(SPAWN is POSIX-common — already wired if your target has fork/exec.)

## 6. Known traps (encoded from the MINIX port, never relearn)

- **strlcpy collision**: if your libc defines strlcpy as a macro,
  `c/sys/syscalls.h` guards it with `#if !defined(strlcpy)`.
- **d_type unreliable**: some FSes return DT_UNKNOWN. Use
  `osif_dirent_kind()` from `posix_common.c` — already does the fallback.
- **No /bin/sh**: never assume it. `bear_osinfo_spawn_capture()`
  uses execv directly with a NULL-terminated argv.
- **mntent vs getmntinfo**: BSD/MINIX/Darwin use getmntinfo; Linux
  /proc/mounts. Pick the right one for your kernel.
- **Page sizes**: pull from `sysconf(_SC_PAGESIZE)` — NEVER hardcode
  4096 (some MIPS/ARM ports use 16 KB pages).
